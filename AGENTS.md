# Glintlabs agent guidance

## Glint UI design system

Before creating or changing HTML reports, visualizations, UI components, color
palettes, spacing, typography, elevation, or responsive behavior, load and
follow:

```text
references/design/glint-ui-system.md
```

The canonical upstream skill is:

```text
https://github.com/employee-experience/EVE-Plugin-Marketplace/tree/main/plugins/eve-design-studio/eve-design-dev/skills/glint-ui-system
```

Treat the Glint UI system as the source of truth. Do not invent colors or mix
unapproved design systems. Preserve accessibility with labels or symbols so
color is never the only signal.
