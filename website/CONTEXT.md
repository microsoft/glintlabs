# Publishing Studio

Shared language for the author-facing workspace that turns an imported Word
report into an approved web report.

## Language

**Canvas**:
The primary report workspace where authors read, select, and directly edit the
web report.
_Avoid_: Preview pane, output panel

**Tool rail**:
The narrow, always-visible left navigation containing the main authoring tools.
_Avoid_: Sidebar, menu

**Contextual panel**:
The closable left-side workspace that opens beside the tool rail and contains
controls for the selected tool or report item.
_Avoid_: Second sidebar, modal

**Studio project**:
A versioned, validated saved report containing the imported manifest, author
edits, readiness status, and source identity.
_Avoid_: Draft file, manifest file

**Reader preview**:
The control-free report experience used to review the current saved Studio
project as a reader would see it.
_Avoid_: Canvas, editor preview
