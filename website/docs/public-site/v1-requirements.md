# Glint Labs v1 requirements

## Public information architecture

The v1 main navigation contains:

- **Glint Labs** — the homepage.
- **Reports** — the public reports index.
- **Tools** — the public tools index.

GitHub is a secondary source destination and does not appear in the main
navigation. Publishing Studio remains available by direct URL but is not part
of the public navigation.

## Homepage

The homepage:

- Features the 2026 Annual Report as the primary story.
- Presents Reports and Tools as the two available v1 destinations.
- Identifies the 2026 Annual Report and Analyze Survey as the real launch
  experiences.
- States plainly that more content will be added when it is ready.
- Does not present invented studies, tools, collaborations, search,
  subscription, or other unfinished capabilities as active destinations.

## Reports

The Reports page:

- Features the 2026 Annual Report as available.
- Links to the existing `/annual-report-2026` experience.
- Uses a general “more reports coming” message rather than invented report
  titles.

## Tools

The Tools page:

- Features Analyze Survey as the only available v1 tool.
- Links to `/tools/analyze-survey`.
- Uses a general “more tools will be added as they are ready” message rather
  than invented tools or categories.

The Analyze Survey page:

- Explains the workflow and generated outputs.
- Links to the canonical `microsoft/glintlabs` source.
- Makes privacy, methodological limitations, and responsible-use expectations
  visible on the page.

## V1 boundaries

The following are not public v1 navigation destinations:

- Search.
- Subscribe.
- Collaborations.
- A broad People Science library.
- Publishing Studio.

Existing placeholder routes may remain available during development, but they
must not imply that unfinished content or functionality is part of the v1
offer.
