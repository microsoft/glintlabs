# Fidelity review

Review items use deterministic codes and retain their source locators.
Approved words and data are locked, so presentation changes cannot hide or
rewrite source-fidelity evidence.

The Issues panel distinguishes blockers from warnings and lets the author
explicitly accept or reopen warnings for the current Studio project. Blockers
cannot be accepted away. Source-review attestation, an intact semantic
fingerprint, and zero blockers are required before publishing.
