## Customize Suggested Action templates in Viva Glint

`customize-suggested-action-templates-in-viva-glint` | catalog | reviewed

**Priority:** Original vault; retained tier `low`.

**Source:** https://learn.microsoft.com/en-us/viva/glint/setup/customize-action-plans

Full Content Resources and Suggested Action Template administration guide. Updates propagate differently to existing Focus Areas depending on state and access path.

**Reviewed asset scope:** Complete freshly retrieved public Microsoft Learn article text reviewed, including substantive tables. Sign-in notices and page chrome excluded as evidence. Linked pages, courses, downloads, recordings and image-only details were not reviewed; no refreshed comprehensive figure or media review is claimed.

1. **Resources precede action templates** (documentation) - Suggested Action Templates provide resources for team-approved Focus Areas. Resources must first exist in Content Resources before attaching to a template; standard prepopulated and customer-uploaded content share this library.
   Topics: glint-admin, action-taking. Evidence: `L19`, "Suggested Action templates contain content that Microsoft Viva Glint includes as suggested resources to help managers achieve team-approved Focus Area".
2. **Driver to template to action items** (documentation) - Choosing a Focus Area from results directs a manager to the Suggested Action Template associated with that survey item's driver. Suggested Action Items are template components; Content Resources include articles, images, PDFs and videos.
   Topics: action-taking, survey-design. Evidence: `L30`, "The overall template associated with a survey item. Choosing a Focus Area from survey results directs managers to the Suggested Action Template associ".
3. **Content Resource field limits** (documentation) - The documented limits are Name 100 characters with no spaces, Title 2048, Description and Rich text 50K+, image/PDF filenames 255 including extension, and video URL 5048. The 50K+ notation is the source's wording, not a precise maximum.
   Topics: glint-admin. Evidence: `L45`, "100, no spaces".
4. **Multilingual resource publishing** (documentation) - Adding a resource adds it for all program languages; select languages individually to modify translations. Save and Publish are separate steps.
   Topics: glint-admin, learning-enablement. Evidence: `L61`, "Select  OK  to confirm that you understand that adding a new resource adds it for all program languages.".
5. **External links require preview and publication** (documentation) - Create external links in a Rich Text resource with URL, label and title plus a short description; preview the destination in the edit pane before saving and publishing.
   Topics: glint-admin, learning-enablement. Evidence: `L69`, "Preview the link in the right edit pane and ensure that the right page appears when the link is selected.".
6. **Prepare an embeddable video resource** (documentation) - For LinkedIn Learning, use Watch full course, Share/Embed and Unlock Video to Embed, then extract only the quoted learning/embed URL from the code. Create a Video resource, select language, describe it, preview the link, save and publish. Other video ownership is supported, following applicable embed instructions.
   Topics: glint-admin, learning-enablement. Evidence: `L81`, "Paste the code into a document to save the entire URL, such as a Word or Google document. Locate the section of the URL, which is within quotes: 'http".
7. **Clone and replace the suggested action** (documentation) - Embed the video via Video Link in the Suggested Action Item. To clone the resource create a new name, then replace the old Suggested Action with the cloned copy in the Focus Area's template and save/publish the change.
   Topics: glint-admin, action-taking. Evidence: `L103`, "To clone this resource, create a new name.".
8. **Completed Focus Area update paths differ** (documentation) - For a Complete Focus Area, adding/editing content from Focus Areas retains original content, whereas adding/editing from Results brings updated content into the Focus Area.
   Topics: glint-admin, action-taking. Evidence: `L119`, "Original content retained in Focus Area".
9. **Open plans retain content; absent plans use updates** (documentation) - Open On track/Off track Focus Areas retain original content whether content is added/edited from Focus Areas or Results. Not-created and Deleted Focus Areas use updated content from either path.
   Topics: glint-admin, action-taking. Evidence: `L122`, "Original content retained in Focus Area".
10. **Refresh retained plan content deliberately** (documentation) - Users can deselect and reselect a Focus Area to pull the latest template/resource content. The guide also recommends dashboard access for recent content and keeping Content Resources current; do not assume an ordinary edit refreshes every existing plan.
