# People Science Knowledge Vault context

The public library is hosted in the repository's `context` folder. No local
reference download or installation is required.

Start with the [context entry](https://raw.githubusercontent.com/microsoft/glintlabs/main/context/people-science-knowledge-vault/README.md)
and follow its topic and source-profile links. Read
[link-only use](https://raw.githubusercontent.com/microsoft/glintlabs/main/context/people-science-knowledge-vault/public-use.md)
for host requirements and limitations.

For an explicitly supplied branch/tag/commit link, resolve these URLs against
that same ref rather than mixing it with main. Local/native skill hosts use
this same public context; this folder is only a pointer, not a second catalog.
